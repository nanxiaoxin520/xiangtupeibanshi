## 4 大核心问题

### 1. 我的痛苦是真实的吗？

答案：是。所有痛苦都是真实的——不管来源于哪里。

你的身体记得（《身体从未忘记》）——症状不是装的。

### 2. 这是谁的问题？

答案：不一定是你的。但是是你的责任。

原生家庭的问题不是你的错（《原生家庭》）——但修复是你的责任。

### 3. 我应该怎么做？

答案：看你的选择。

- 接受并改变（《少有人走的路》）
- 接受并分离（《被讨厌的勇气》）
- 设定界限（《过犹不及》）

### 4. 我会好吗？

答案：会。但需要时间和努力。

- 约 30% 的人会获得获得性安全（《依恋》）
- 创伤可以治愈（《身体从未忘记》）
- 心智可以成熟（《少有人走的路》）

## 4 大基本矛盾点

### 1. 爱和界限的矛盾

- 爱说我为你做一切
- 界限说我为自己负责
- 真正的爱 = 两者都做（《过犹不及》）

### 2. 期望和现实的矛盾

- 我们爱对方的理想化（《亲密关系》）
- 对方是真实的人（不完美）
- 如何接受真实的对方？

### 3. 关系和自我的矛盾

- 中国人的自我是在关系中的（差序格局）
- 但也需要自我的自由（《被讨厌的勇气》）
- 两者可以兼有

### 4. 内圈义务和自主的矛盾

- 家庭有义务（中国文化）
- 个体需要自主（现代趋势）
- 如何在义务中找到自己？

## 4 大根本矛盾点

### 1. 关系是痛苦的来源，也是治愈的载体

- **关系创伤**是痛苦的来源
- **新关系**是治愈的载体
- 这是一个悖论——《身体从未忘记》

### 2. 我们在关系中失去自我，但只有关系能找回自我

- **关系中**失去自我（创伤）
- **新关系中**找回自我（治愈）
- 这需要新的关系（《依恋》）

### 3. 中国家庭的双面性——爱和伤害都是真实的

- **爱**是真实的（父母真的爱你）
- **伤害**也是真实的（但也是真的伤害了你）
- 两者并存——《原生家庭》

### 4. 自由和连接的永恒张力

- **自由**（《被讨厌的勇气》）
- **连接**（差序格局）
- 不是 0 或 1——是动态平衡

## 安慰：这一节不是话术库

禁止把本节任何句子原样发给用户。一句安慰合不合格只看一条：它有没有点中这个人刚才说出的那件具体的事（`SKILL.md`「说话方式」第 3、7 条）。

### 原来这里的 10 句通用话术已撤回

它们套在任何人身上都成立，正是"安慰没安慰到点上"的来源。撤回的 10 句是：你的感受是真实的 / 这不是你的错 / 你可以爱也可以不接受 / 你的关系模式不是你的错 / 你可以说不 / 你可以受伤也可以成长 / 你可以改变 / 你值得被爱 / 你的身体记得 / 寻求帮助是力量。

其中 3 句属于有毒鸡汤，永久不再使用：

- 「痛苦是成长的入口。回避痛苦 = 不成熟」——美化苦难，还顺手指责了用户。
- 「你值得被爱——不是因为你做了什么，是因为你存在」——没有落点的套话，接不住任何具体处境。
- 「寻求帮助不是软弱——是力量」——说教，把责任又放回用户身上。

### 留下的 7 个意图，必须现场填满才可以说

| 意图 | 填满才成立 | 空的（不合格） |
|---|---|---|
| 她的痛苦是真的 | 说出她那件事：守了几天院、挨了哪一句 | 「你的感受是真实的」 |
| 不全怪她 | 指出哪一块本来不由她负责 | 「这不是你的错」 |
| 爱与伤害并存 | 用她说过的两种感受对上 | 「父母也是为你好」 |
| 她可以拒绝 | 落到她下次要推掉的那件具体事 | 「你要学会说不」 |
| 她的身体记得 | 说她自己的症状：失眠、心慌、吃不下 | 「身体会记住创伤」 |
| 它会慢慢变 | 给一个她自己能验证的小窗口 | 「会好起来的」 |
| 找人不丢人 | 说清找谁、开口说什么、最坏是怎样 | 「寻求帮助是力量」 |

### 填不出来时的兜底

手上没有细节，就只复述她说过的话，不加判断、不补意义：

> 你刚那句"就我多事"，我记住了。

这比任何一句漂亮的通用句更接近被听见。

## 解决方向（短期/中期/长期）

这是给陪伴者看的路线图，不是发给用户的清单。每轮只提她眼下够得着的那一件（`SKILL.md`「说话方式」第 1、5 条）。

### 短期（1-2 周）

- **识别**你在关系中的痛苦是什么
- **写**下来（不要只在脑子里想）
- **找**一个倾听者（朋友、咨询师）
- **不**做重大决定

### 中期（1-3 月）

- **学习**识别自己的模式
- **学习**设定界限的技巧
- **学习**沟通（I 陈述）
- **练习**新行为

### 长期（持续）

- **修复**重要的关系（如果可以）
- **建立**新的健康关系
- **成为**你想成为的人
- **传承**你学到的东西
