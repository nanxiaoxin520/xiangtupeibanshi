# 认知重构（差序格局视角）

## 什么是认知重构

**认知重构** = 识别和改变不适应的思维模式。

**核心思想**（Beck 认知模型）：
- 不是事件本身让我们难受
- 是我们对事件的看法让我们难受
- 改变看法 = 改变情绪和行为

## 常见认知歪曲

### 1. 全或无思维

- 如果我不完美，我就是失败的
- 改为：有进步就是进步

### 2. 灾难化

- 这太糟糕了
- 改为：这是挑战，不是结束

### 3. 过度概括

- 总是、从不
- 改为：有时候会，有时候不会

### 4. 选择性注意

- 只看负面
- 改为：什么是正面的？

### 5. 个人化

- 都是我的错
- 改为：有多少因素？

### 6. 应该思维

- 我应该
- 改为：我希望

### 7. 读心术

- 他肯定觉得我很差
- 改为：有什么证据？

## 差序格局视角的认知重构

中国**家**庭**/关**系**中**的**特**有**思**维**模**式**：

### 1. "我应该让家人高兴"

- 改成："我**可以**让家人高兴**同**时**也**让**自**己**好**受**吗**？"
- 探**讨**协**商**的**空**间**

### 2. "他们不爱我"

- 改成："他**们**的**关**心**方**式**可**能**是**什**么**？"
- 帮**助**看**到**内**圈**的**不**同**表**达**

### 3. "我不孝"

- 改成："什**么**是**孝**？**只**有**一**种**形**式**吗**？"
- 探**讨**中**国**的**孝**文**化**（**不**是**绝**对**服**从**）

### 4. "别人怎么看我"

- 改成："是**谁**在**看**？**（**内**圈**、**中**圈**、**外**圈**）**"
- 帮**助**区**分**不**同**圈**的**期**望**

## 思维记录表

**5 列记录**：

| 列 | 内容 |
|---|---|
| 情境 | 发生了什么（涉及谁？） |
| 圈 | 内/中/外？ |
| 自动思维 | 想到了什么 |
| 情绪 | 感受到什么 |
| 替代思维 | 更平衡的想法 |

## 简单的对话

### 识别歪曲
> 你听到自己在说'总是'或'从不'吗？
>
> 你的思维是在'应该'什么？

### 找证据
> 支持这个想法的证据是什么？
>
> 反对的证据呢？

### 替代思维
> 如果你的朋友这样想，你会对他说什么？
>
> 这**件事**涉**及**的**是**哪**个**圈**？**那**个**圈**的**规**则**是**什**么**？
