# 评估量表速查

> **按需加载**——本 skill 不强迫做量表，但危机/严重评估时必用。

## 1. PHQ-9（Patient Health Questionnaire-9）

**用**途**：**抑郁**严重程度**评**估**。

**9** 个**问**题**，**对**应** D**S**M**-**5** 的 **9** 大**症**状**。

**评**分**：

| 分值 | 严重程度 | 行动 |
|---|---|---|
| 0-4 | 无/轻微 | 一般支持 |
| 5-9 | 轻度 | 陪伴 + 监测 |
| 10-14 | 中度 | 陪伴 + 建议专业评估 |
| 15-19 | 中重度 | **必须**转介专业 |
| 20-27 | 重度 | **立即**转介 + 危机关注 |

**自**杀**项**（**第** 9** 题**）**= 1** 分**以**上**——**立即**危**险**评**估**！

## 2. GAD-7（Generalized Anxiety Disorder-7）

**用**途**：**广**泛**性**焦**虑**症**筛**查**。

**7** 个**问**题**，**0-3** 评**分**。

| 分值 | 严重程度 |
|---|---|
| 0-4 | 轻微 |
| 5-9 | 轻度 |
| 10-14 | 中度 |
| 15-21 | 重度 |

## 3. PSS（Perceived Stress Scale）

**用**途**：**知**觉**压**力**评**估**。

**10** 个**问**题**（**或** 14** 题**版**本**），**0-4** 评**分**。

| 分值 | 压力水平 |
|---|---|
| 0-13 | 低 |
| 14-26 | 中 |
| 27-40 | 高 |

## 4. DASS-21（Depression Anxiety Stress Scales）

**用**途**：**抑**郁** + **焦**虑** + **压**力** 三**维**度**评**估**。

**21** 个**问**题**，**三**个**子**量**表**各** 7** 题**。

| 子量表 | 正常 | 轻度 | 中度 | 重度 | 极重 |
|---|---|---|---|---|---|
| 抑郁 | 0-4 | 5-6 | 7-10 | 11-13 | 14+ |
| 焦虑 | 0-3 | 4-5 | 6-7 | 8-9 | 10+ |
| 压力 | 0-7 | 8-9 | 10-12 | 13-16 | 17+ |

## 5. 关系评估（差序版）

**评**估**内**圈**、**中**圈**、**外**圈**的**关**系**质**量**。

**每**圈** 5** 个**问**题**（**0-4** 评**分**）**：

### 内圈（家人）

1. 与父母的关系质量
2. 与配偶/伴侣的关系质量
3. 与子女的关系质量
4. 与自己的关系（自我接纳）
5. 家庭功能的整体评价

### 中圈（熟人）

1. 真正的朋友数量
2. 与同事的关系质量
3. 参与社群的程度
4. 有困难时能求助的人
5. 整体支持系统

### 外圈（社会）

1. 对社会的信任度
2. 公共资源可及性
3. 对未来的信心
4. 归属感
5. 整体社会连接

## 6. 危机评估（C-SSRS）

**用**途**：**自**杀**风**险**评**估**。

**6** 个**核**心**问**题**：

1. 过去是否有自杀念头？
2. 过去是否有自杀愿望？
3. 过去是否有自杀计划？
4. 过去是否有自杀行为？
5. 未来是否有自杀念头？
6. 未来是否有自杀计划？

**任**何**"**是**"**——**立**即**危**险**评**估**！

## 何时使用量表

| 情境 | 必用 | 选用 |
|---|---|---|
| 首次咨询 | - | PHQ-9 + GAD-7 |
| 怀疑抑郁 | PHQ-9 | - |
| 怀疑焦虑 | GAD-7 | - |
| 自杀风险 | C-SSRS | - |
| 长期压力 | - | PSS 或 DASS-21 |
| 关系问题 | 差序评估 | - |
| 严重心理问题 | PHQ-9 + GAD-7 + C-SSRS | - |

## 使用注意

- **量**表**是**工**具**——**不**是**诊**断**
- **结**果**需**要**结**合**临**床**访**谈**
- **不**是**所**有**人**都**需**要**量**表**
- **中**国**语**境**需**要**本**土**化**解**释**
