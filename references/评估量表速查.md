# 评估量表速查

> **按需加载**——本 skill 不强迫做量表，但危机/严重评估时必用。

## 1. PHQ-9（Patient Health Questionnaire-9）

用途：抑郁严重程度评估。

9 个问题，对应 DSM-5 的 9 大症状。

评分：

| 分值 | 严重程度 | 行动 |
|---|---|---|
| 0-4 | 无/轻微 | 一般支持 |
| 5-9 | 轻度 | 陪伴 + 监测 |
| 10-14 | 中度 | 陪伴 + 建议专业评估 |
| 15-19 | 中重度 | **必须**转介专业 |
| 20-27 | 重度 | **立即**转介 + 危机关注 |

自杀项（第 9 题）= 1 分以上——立即危险评估！

## 2. GAD-7（Generalized Anxiety Disorder-7）

用途：广泛性焦虑症筛查。

7 个问题，0-3 评分。

| 分值 | 严重程度 |
|---|---|
| 0-4 | 轻微 |
| 5-9 | 轻度 |
| 10-14 | 中度 |
| 15-21 | 重度 |

## 3. PSS（Perceived Stress Scale）

用途：知觉压力评估。

10 个问题（或 14 题版本），0-4 评分。

| 分值 | 压力水平 |
|---|---|
| 0-13 | 低 |
| 14-26 | 中 |
| 27-40 | 高 |

## 4. DASS-21（Depression Anxiety Stress Scales）

用途：抑郁 + 焦虑 + 压力 三维度评估。

21 个问题，三个子量表各 7 题。

| 子量表 | 正常 | 轻度 | 中度 | 重度 | 极重 |
|---|---|---|---|---|---|
| 抑郁 | 0-4 | 5-6 | 7-10 | 11-13 | 14+ |
| 焦虑 | 0-3 | 4-5 | 6-7 | 8-9 | 10+ |
| 压力 | 0-7 | 8-9 | 10-12 | 13-16 | 17+ |

## 5. 关系评估（差序版）

评估内圈、中圈、外圈的关系质量。

每圈 5 个问题（0-4 评分）：

### 内圈（家人）

1. 与父母的关系质量
2. 与配偶/伴侣的关系质量
3. 与子女的关系质量
4. 与自己的关系（自我接纳）
5. 家庭功能的整体评价

### 中圈（熟人）

1. 真正的朋友数量
2. 与同事的关系质量
3. 参与社群的程度
4. 有困难时能求助的人
5. 整体支持系统

### 外圈（社会）

1. 对社会的信任度
2. 公共资源可及性
3. 对未来的信心
4. 归属感
5. 整体社会连接

## 6. 危机评估（C-SSRS）

用途：自杀风险评估。

6 个核心问题：

1. 过去是否有自杀念头？
2. 过去是否有自杀愿望？
3. 过去是否有自杀计划？
4. 过去是否有自杀行为？
5. 未来是否有自杀念头？
6. 未来是否有自杀计划？

任何"是"——立即危险评估！

## 何时使用量表

| 情境 | 必用 | 选用 |
|---|---|---|
| 首次咨询 | - | PHQ-9 + GAD-7 |
| 怀疑抑郁 | PHQ-9 | - |
| 怀疑焦虑 | GAD-7 | - |
| 自杀风险 | C-SSRS | - |
| 长期压力 | - | PSS 或 DASS-21 |
| 关系问题 | 差序评估 | - |
| 严重心理问题 | PHQ-9 + GAD-7 + C-SSRS | - |

## 使用注意

- 量表是工具——不是诊断
- 结果需要结合临床访谈
- 不是所有人都需要量表
- 中国语境需要本土化解释
