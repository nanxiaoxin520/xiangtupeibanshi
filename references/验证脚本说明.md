# 验证脚本说明

> **按需加载**——`scripts/validate_skill.py` 的完整文档。
>
> 本文件描述的是**实际实现**的检查项。脚本与本文档必须保持同步：新增检查项时同步更新本文档。

## 1. 运行方式

```bash
# 在仓库根目录
python scripts/validate_skill.py

# 仅输出失败项
python scripts/validate_skill.py --quiet
```

**零外部依赖**——脚本不使用 PyYAML，frontmatter 由内置的扁平解析器处理，
以维持本仓库「无依赖」的设计声明（见 `documentation/permissions.md`）。

## 2. 输出格式

**成功**：

```
xiangtupeibanshi validation passed
```

**失败**：

```
ERROR: <具体错误>
...
xiangtupeibanshi validation failed（N 项错误）
```

退出码：`0` = 通过；`1` = 存在 ERROR。WARN 不影响退出码。

## 3. 检查项清单（12 类）

| # | 检查项 | 函数 | 说明 |
|---|---|---|---|
| 1 | Front Matter 规范 | `check_skill_frontmatter` | 键须恰为 `name` + `description`；`name` 须等于 `xiangtupeibanshi` 且匹配 `[a-z0-9-]{1,64}`；`description` 非空、≤1024 字符、不含 `<` `>` |
| 2 | 内核预算 | `check_skill_budget` | `SKILL.md` ≤200 行 / ≤8000 字符 / ≤7000 近似 token |
| 3 | **内核结构完整性** | `check_skill_structure` | 必须含加载协议、角色、创伤知情、差序格局、5 步流程、危机转介、伦理边界、**按议题路由表**、限制声明；且路由表指向的 guides 必须真实存在 |
| 4 | 清单完整性 | `check_inventory` | 13 个必需路径 + 19 篇必需 guides 存在 |
| 5 | 断链 | `check_links` | 覆盖 Markdown 链接、反引号路径、**表格内裸文件名**；按仓库相对路径与各子目录两种基准解析 |
| 6 | 占位符 | `check_placeholders` | `[TODO` / `[PLACEHOLDER]` / `{{ 模板变量` / `FIXME` / `XXX`；排除行内代码段与 GitHub Actions 的 `${{ }}` |
| 7 | 命名规范 | `check_forbidden_terms` | 禁止 `xiangupeibanshi` / `xiangtupeiubanshi` / `hometown-companion` / `xinli-zhushou`（大小写不敏感）；白名单：`CHANGELOG.md`、`CONTRIBUTING.md`、`README.md` |
| 8 | 加粗格式污染 | `check_bold_pollution` | 检测「隔字加粗」（`本文档）；排除 frontmatter 与代码块 |
| 9 | **热线正确性** | `check_hotlines` | 权威源须含 `verified_at` 与核心号码；禁止 `12356`、`2022 新设`；`400-821-1215` 不得标为 24 小时（排除「非 24 小时」表述） |
| 10 | 书籍档案卡 | `check_books` | 每张卡须有 Front Matter 且含 `title` / `author` / `type`，并含「未读边界」声明 |
| 11 | 版本一致性 | `check_versions` | `VERSION` 须出现在 `CHANGELOG.md`；`SKILL.md` 若含 `version` 须与 `VERSION` 一致 |
| 12 | 清单计数一致 | `check_manifest` | `docs/manifest.yaml` 声明的 guides / examples / references / documentation / books 数量须与文件系统实际值一致 |

## 4. 相关脚本

| 脚本 | 作用 |
|---|---|
| `scripts/validate_skill.py` | 本文件描述的校验器 |
| `scripts/clean_bold.py` | 清理加粗污染。`--dry-run` 预览 / `--write` 修复 / `--check` CI 检查 |
| `scripts/fix_hotlines.py` | 批量修正热线写法。`--dry-run` 预览 / `--write` 修复（自动跳过 `CHANGELOG.md`） |

## 5. 常见错误及修复

| 错误 | 修复 |
|---|---|
| `SKILL.md 缺少必需结构「按议题路由表」` | 在 `SKILL.md` 恢复「## 按议题查找」表 |
| `SKILL.md 超过 200 行` | 用表格替代列表压缩内容 |
| `missing required guide` | 创建缺失的 guide 或从 `REQUIRED_GUIDES` 移除 |
| `broken link in ...` | 修正路径或创建目标文件 |
| `加粗格式污染` | 运行 `python scripts/clean_bold.py --write` |
| `热线写法错误 ... 12356` | 运行 `python scripts/fix_hotlines.py --write` |
| `命名禁用变体` | 统一为 `xiangtupeibanshi` |
| `manifest.yaml guides=N 与实际 M 不一致` | 更新 `docs/manifest.yaml` |
| `frontmatter 第 N 行存在意外缩进` | 本仓库约定 frontmatter 为扁平键值，去除缩进 |
