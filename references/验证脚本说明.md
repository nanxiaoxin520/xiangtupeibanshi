# 验证脚本说明

> **按需加载**——`scripts/validate_skill.py` 的完整文档。

## 1. 验证内容

### 必需文件检查
- `SKILL.md` 存在
- `agents/openai.yaml` 存在
- `references/` 目录存在
- `guides/` 目录存在
- `examples/` 目录存在
- `scripts/validate_skill.py` 存在

### SKILL.md 结构验证
- Front matter 完整（name, description）
- 角色定义（乡伴）
- 核心框架（差序格局、3维评估、4阶段、5层资源）
- 5步对话流程
- 危机识别与转介
- 伦理边界（4大边界映射7大原则）
- 按议题查找表（guides 路由）
- 限制声明

### SKILL.md 长度限制
- ≤ 200 行
- ≤ 8000 字符
- ≤ 7000 tokens（估算）

### Front Matter 验证
- 必需字段：name, description
- description 非空

### 交叉引用验证
- SKILL.md 中引用的 guides 文件是否存在
- SKILL.md 中引用的 references 文件是否存在
- guides 中引用的 _books 档案卡是否存在

### 无残留检查
- 检查无 "g-*-*****-**" 等残留（白名单：CHANGELOG.md, CONTRIBUTING.md, README.md）
- 检查无死链

### _books 档案卡验证
- 每个 .md 文件有 Front matter
- 必需字段：title, author, type
- 包含"重要的未读边界"声明

### guides 验证
- 每个 guide 有必要的结构

## 2. 运行方式

```bash
# 在 skill 根目录
python scripts/validate_skill.py
```

## 3. 输出

**成功**：
```
xinli-zhushou validation passed
```

**失败**：

## 5. 常见错误及修复

| 错误 | 修复 |
|---|---|
| SKILL.md > 200 lines | 缩短内容，用表格替代列表 |
| 缺少 guide 文件 | 创建缺失的 guide |
| 交叉引用断链 | 修正路径或创建文件 |
| g-*-*****-** 残留 | 删除或加入白名单 |
| _books 无 Front matter | 补全 Front matter |
| "未读边界" 缺失 | 补全声明 |
