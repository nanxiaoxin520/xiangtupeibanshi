# 验证脚本说明

> **按需加载**——`scripts/validate_skill.py` 的完整文档。
>
> 本文件描述的是**实际实现**的检查项。脚本与本文档必须保持同步：新增检查项时同步更新本文档。

## 1. 运行方式

```bash
# 在仓库根目录
python scripts/validate_skill.py

# 仅输出失败项
python scripts/validate_skill.py --quiet
```

**零外部依赖**——脚本不使用 PyYAML，frontmatter 由内置的扁平解析器处理，
以维持本仓库「无依赖」的设计声明（见 `documentation/permissions.md`）。

## 2. 输出格式

**成功**：

```
xiangtupeibanshi validation passed
```

**失败**：

```
ERROR: <具体错误>
...
xiangtupeibanshi validation failed（N 项错误）
```

退出码：`0` = 通过；`1` = 存在 ERROR。WARN 不影响退出码。

## 5. 常见错误及修复

| 错误 | 修复 |
|---|---|
| `SKILL.md 缺少必需结构「按议题路由表」` | 在 `SKILL.md` 恢复「## 按议题查找」表 |
| `SKILL.md 超过 200 行` | 用表格替代列表压缩内容 |
| `missing required guide` | 创建缺失的 guide 或从 `REQUIRED_GUIDES` 移除 |
| `broken link in ...` | 修正路径或创建目标文件 |
| `加粗格式污染` | 运行 `python scripts/clean_bold.py --write` |
| `热线写法错误 ... 12356` | 运行 `python scripts/fix_hotlines.py --write` |
| `将 400-821-1215 列在小节「…（24h）」下` | 把该号码移出 24 小时小节，单列「时段受限」小节并写明 `10:00–22:00`；号码与服务时间以 `references/热线与资源速查.md` 为准 |
| `口吻回归 … 一条回复 N 问` | 把提问拆到不同轮次（`SKILL.md`「说话方式」第 4 条） |

## 7. 写作约定：如何引用被禁写法：如何引用被禁写法

四类内容检查（命名变体、历史残留术语、热线写法、口吻回归）只承认两种通用豁免：白名单文件、行内代码段。
把反例写成 `「某某」` 或 “某某” 都会被判定为真实违规，`fix_hotlines.py --write` 也会改写它们。
因此：**凡把被禁写法当例子书写，必须用反引号包起来**（如本表第 9 行）。
校验器与修正器都先剥离行内代码再判定，两者在这一约定上行为一致。

口吻回归（第 10 项）另有三条自身豁免，写反例时按它走：

- 示范用的小节标题须含「反面」「不要模仿」「要是」「岔开」之一——该小节内的旧式整块回复不参与判定。
- 篇首 `> **相关指南**：…` 一类导读块允许出现内部路径，它们不是发给用户的句子。
- 禁用鸡汤要写成带否定标记的引用（`不说「想开点」`、`不写"你已经很棒了"`），标记须在禁句前四字内；只写「以下为禁用清单」这类无否定标记的列举会被判错。
