# 治疗流派速查

> **按需加载**——本 skill 基于 CBT/ACT/正念，兼容其他流派。

## 1. CBT（认知行为治疗）

核心：认知决定情绪和行为。

三角模型：情境 → 认知 → 情绪/行为。

核心技术：

| 技术 | 用途 |
|---|---|
| 思维记录 | 识别自动思维 |
| 认知重构 | 挑战非理性信念 |
| 行为激活 | 对抗抑郁的退缩 |
| 暴露疗法 | 对抗焦虑的回避 |
| 问题解决 | 实用技能 |

适用：抑郁、焦虑、强迫、PTSD、饮食障碍。

证据：A 级。

## 2. ACT（接纳承诺治疗）

核心：心理灵活性——接纳不可控的、承诺有意义的行动。

六大核心过程（Hexaflex）：

| 过程 | 含义 | 反面 |
|---|---|---|
| 接纳（Acceptance） | 容许体验存在 | 回避 |
| 认知解离（Defusion） | 念头是念头——不是事实 | 融合 |
| 存在（Present Moment） | 这里和现在 | 过去/未来 |
| 自我为背景（Self-as-Context） | 观察者我 | 内容我 |
| 价值（Values） | 什么重要 | 目标 |
| 承诺行动（Committed Action） | 按价值行动 | 惰性/逃避 |

适用：慢性疼痛、抑郁、焦虑、药物依赖。

核心话术："你的念头不是你的主人"。

## 3. 正念（Mindfulness / MBSR）

核心：非评判地觉察当下的体验。

7 个态度（卡巴金）：

1. 非评判
2. **耐**心
3. **初**心
4. **信**任
5. **不**争
6. **接**纳
7. **放**下

标准课程：8 周 MBSR（45 分钟/天家庭练习）。

适用：压力、焦虑、抑郁、慢性疼痛。

核心话术："觉察你的呼吸——念头来了就让它走"。

## 4. DBT（辩证行为治疗）

核心：辩证——接纳和改变同时进行。

4 大模块技能：

| 模块 | 内容 |
|---|---|
| 核心正念 | 观察、描述、参与 |
| 情绪调节 | 理解情绪、改变情绪 |
| 人际效能 | DEAR MAN / GIVE / FAST |
| 耐受力 | TIPP / ACCEPTS / 自我安抚 |

适用：边缘性人格、自杀、自伤、物质依赖。

证据：A 级。

## 5. EFT（情绪聚焦治疗）

核心：情绪是改变的载体——不是认知。

依恋理论基础——苏珊·约翰逊。

3 个阶段 + 9 个步骤：

1. 去激化（De-escalation）
2. 重塑关系（Restructuring）
3. 巩固（Consolidation）

7 次对话：
- 追逃循环识别
- 核心伤害触及
- 脆弱表达
- 接纳对方
- 重塑连接
- 维持连接

**证**据：**A** 级（RCT）。

## 6. 精神动力学/精神分析

核心：无意识冲突和早年经验。

关键概念：
- 防御机制
- **移**情/反**移**情
- **阻**抗
- **修**通
- 自我结构

适用：人格障碍、慢性问题、深度探索。

时间：长期（50+ 次）。

## 7. 系统家庭治疗

核心：家庭是系统——个体问题是系统症状。

主要流派：
- 结构式（Minuchin）——边界、联盟
- 策略式（Haley/Madanes）——指令
- 鲍文式（Bowen）——分化自我
- 叙事式（White/Epston）——外部化问题

适用：家庭冲突、孩子问题、伴侣关系。

## 8. 以人为中心/人本主义

核心：治疗师的态度是核心。

3 大核心条件（罗杰斯）：

1. 无条件积极关注
2. **共**情
3. **真**实/一**致**性

适用：自我探索、成长、关系建立。

## 9. 存在主义治疗

核心：存在的4 大终极关注（亚隆）：

1. **死**亡
2. **自**由
3. **孤**独
4. **无**意义

适用：存在危机、意义缺失、围产期。

## 10. 叙事治疗

核心：人生是故事——重写故事。

核心技术：
- 外部化问题（"问题是问题，你不是问题"）
- 独特结局
- 重新作者身份

## 11. 解决中心短程治疗（SFBT）

核心：解决方案比问题重要。

核心技术：
- 奇迹问题（"如果奇迹发生..."）
- 例外寻找（"什么时候好一点？"）
- 量表问题（1-10 分）

## 12. 情绪建构理论

核心：情绪是大脑构建的——不是普遍的。

关键概念：
- 内感受
- 情绪概念
- 预测编码
- 情绪粒度

意义：情绪可以改变——学习新的情绪概念。

## 流派选择指南

| 来访者需求 | 首选 | 备选 |
|---|---|---|
| 抑郁（轻中度） | CBT | ACT |
| 焦虑/恐惧症 | CBT + 暴露 | ACT |
| 边缘型人格/自杀 | DBT | 精神动力学 |
| 伴侣冲突 | EFT | Gottman |
| 家庭冲突 | 结构式/鲍文 | 叙事 |
| 创伤/PTSD | EMDR + CBT | EFT + 暴露 |
| 自我探索/成长 | 人本主义/存在主义 | ACT |
| 重复关系模式 | 精神动力学 | EFT |
| 中国文化语境 | 差序格局 + CBT/ACT | EFT |

## 本 skill 的整合策略

主要基础：CBT + ACT + 正念。

中国文化框架：差序格局 + 关系主义。

整合方式：
- 评估用差序3 维
- 干预用CBT/ACT/正念技能
- 关系用差序格局 + EFT
- 危机用C-SSRS + 6 步危机干预

不做：长程精神分析、家庭治疗、伴侣治疗（超出能力）。
