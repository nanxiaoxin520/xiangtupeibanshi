# 治疗流派速查

> **按需加载**——本 skill 基于 CBT/ACT/正念，兼容其他流派。

## 1. CBT（认知行为治疗）

**核**心**：**认**知**决**定**情**绪**和**行**为**。

**三**角**模**型**：情**境** → **认**知** → **情**绪**/行**为**。

**核**心**技**术**：

| 技术 | 用途 |
|---|---|
| **思**维**记**录** | 识**别**自**动**思**维** |
| **认**知**重**构** | 挑**战**非**理**性**信**念** |
| **行**为**激**活** | 对**抗**抑**郁**的**退**缩** |
| **暴**露**疗**法** | 对**抗**焦**虑**的**回**避** |
| **问**题**解**决** | 实**用**技**能** |

**适**用**：**抑**郁**、**焦**虑**、**强**迫**、**P**T**S**D**、**饮**食**障**碍**。

**证**据**：**A** 级。

## 2. ACT（接纳承诺治疗）

**核**心**：**心**理**灵**活**性**——**接**纳**不**可**控**的**、**承**诺**有**意**义**的**行**动**。

**六**大**核**心**过**程**（Hexaflex）：

| 过程 | 含义 | 反面 |
|---|---|---|
| **接**纳**（Acceptance）** | 容**许**体**验**存**在** | **回**避** |
| **认**知**解**离**（Defusion）** | **念**头**是**念**头**——**不**是**事**实** | **融**合** |
| **存**在**（Present Moment）** | **这**里**和**现**在** | **过**去**/**未**来** |
| **自**我**为**背**景**（Self-as-Context）** | **观**察**者**我** | **内**容**我** |
| **价**值**（Values）** | **什**么**重**要** | **目**标** |
| **承**诺**行**动**（Committed Action）** | **按**价**值**行**动** | **惰**性**/逃**避** |

**适**用**：**慢**性**疼**痛**、**抑**郁**、**焦**虑**、**药**物**依**赖**。

**核**心**话**术**："**你**的**念**头**不**是**你**的**主**人**"**。

## 3. 正念（Mindfulness / MBSR）

**核**心**：**非**评**判**地**觉**察**当**下**的**体**验**。

**7** 个**态**度**（卡巴金）：

1. **非**评**判**
2. **耐**心
3. **初**心
4. **信**任
5. **不**争
6. **接**纳
7. **放**下

**标**准**课**程**：**8** 周 **M**B**S**R**（**45** 分钟/天**家**庭**练**习**）。

**适**用**：**压**力**、**焦**虑**、**抑**郁**、**慢**性**疼**痛**。

**核**心**话**术**："**觉**察**你**的**呼**吸**——**念**头**来**了**就**让**它**走**"**。

## 4. DBT（辩证行为治疗）

**核**心：**辩**证**——**接**纳**和**改**变**同**时**进**行**。

**4** 大**模**块**技**能**：

| 模块 | 内容 |
|---|---|
| **核**心**正**念** | 观**察**、**描**述、**参**与** |
| **情**绪**调**节** | 理**解**情**绪**、**改**变**情**绪** |
| **人**际**效**能** | **DE**A**R** **M**A**N** / **G**I**V**E** / **F**A**S**T** |
| **耐**受**力** | **TI**P**P** / **A**C**C**E**P**T**S** / **自**我**安**抚** |

**适**用**：**边**缘**性**人**格**、**自**杀**、**自**伤**、**物**质**依**赖**。

**证**据**：**A** 级。

## 5. EFT（情绪聚焦治疗）

**核**心：**情**绪**是**改**变**的**载**体**——**不**是**认**知**。

**依**恋**理**论**基**础**——**苏**珊**·**约**翰**逊**。

**3** 个**阶**段** + **9** 个**步**骤**：

1. **去**激**化**（De-escalation）
2. **重**塑**关**系**（Restructuring）
3. **巩**固**（Consolidation）

**7** 次**对**话**：
- 追**逃**循**环**识**别**
- 核**心**伤**害**触**及**
- 脆**弱**表**达**
- 接**纳**对**方**
- 重**塑**连**接**
- 维**持**连**接**

**证**据：**A** 级（RCT）。

## 6. 精神动力学/精神分析

**核**心：**无**意**识**冲**突**和**早**年**经**验**。

**关**键**概**念**：
- **防**御**机**制
- **移**情/反**移**情
- **阻**抗
- **修**通
- **自**我**结**构

**适**用：**人**格**障**碍**、**慢**性**问**题**、**深**度**探**索**。

**时**间：**长**期**（50**+** 次**）**。

## 7. 系统家庭治疗

**核**心：**家**庭**是**系**统**——**个**体**问**题**是**系**统**症**状**。

**主**要**流**派**：
- **结**构**式**（Minuchin）——**边**界**、**联**盟
- **策**略**式**（Haley/Madanes）——**指**令
- **鲍**文**式**（Bowen）——**分**化**自**我**
- **叙**事**式**（White/Epston）——**外**部**化**问**题**

**适**用：**家**庭**冲**突**、**孩**子**问**题**、**伴**侣**关**系**。

## 8. 以人为中心/人本主义

**核**心：**治**疗**师**的**态**度**是**核**心**。

**3** 大**核**心**条**件**（罗杰斯）：

1. **无**条**件**积**极**关**注
2. **共**情
3. **真**实/一**致**性

**适**用：**自**我**探**索**、**成**长**、**关**系**建**立**。

## 9. 存在主义治疗

**核**心：**存**在**的**4** 大**终**极**关**注**（亚隆）：

1. **死**亡
2. **自**由
3. **孤**独
4. **无**意义

**适**用：**存**在**危**机**、**意**义**缺**失**、**围**产**期**。

## 10. 叙事治疗

**核**心：**人**生**是**故**事**——**重**写**故**事**。

**核**心**技**术**：
- **外**部**化**问**题**（"问**题**是**问**题**，**你**不**是**问**题**"**）
- **独**特**结**局**
- **重**新**作**者**身**份**

## 11. 解决中心短程治疗（SFBT）

**核**心：**解**决**方**案**比**问**题**重**要**。

**核**心**技**术**：
- **奇**迹**问**题**（"**如**果**奇**迹**发**生**..."**）
- **例**外**寻**找**（"**什**么**时**候**好**一**点**？**"**）
- **量**表**问**题**（**1-10** 分**）

## 12. 情绪建构理论

**核**心：**情**绪**是**大**脑**构**建**的**——**不**是**普**遍**的**。

**关**键**概**念**：
- **内**感**受**
- **情**绪**概**念
- **预**测**编**码**
- **情**绪**粒**度

**意**义：**情**绪**可**以**改**变**——**学**习**新**的**情**绪**概**念**。

## 流派选择指南

| 来访者需求 | 首选 | 备选 |
|---|---|---|
| 抑郁（轻中度） | CBT | ACT |
| 焦虑/恐惧症 | CBT + 暴露 | ACT |
| 边缘型人格/自杀 | DBT | 精神动力学 |
| 伴侣冲突 | EFT | Gottman |
| 家庭冲突 | 结构式/鲍文 | 叙事 |
| 创伤/PTSD | EMDR + CBT | EFT + 暴露 |
| 自我探索/成长 | 人本主义/存在主义 | ACT |
| 重复关系模式 | 精神动力学 | EFT |
| 中国文化语境 | 差序格局 + CBT/ACT | EFT |

## 本 skill 的整合策略

**主**要**基**础**：**C**B**T** + **A**C**T** + **正**念。

**中**国**文化**框**架**：**差**序**格**局** + **关系**主**义**。

**整**合**方**式**：
- **评**估用**差**序**3** 维
- **干**预用**C**B**T**/**A**C**T**/**正**念**技**能**
- **关**系**用**差**序**格**局** + **E**F**T**
- **危**机**用**C-SSRS + 6 步危机干预

**不**做：**长**程**精神**分**析**、**家**庭**治**疗**、**伴**侣**治**疗**（超**出**能**力**）。
