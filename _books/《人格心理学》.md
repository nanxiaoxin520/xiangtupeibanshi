# 《人格心理学》

## 基础信息

- **作者**：杰瑞·伯格 (Jerry M. Burger)
- *Personality Psychology* 是**经**典**的**人**格**心**理**学**教**材**

## 真实学术信息

**伯**格**的**核**心**贡**献**——

- 美**国**人**格**心**理**学**的**主**要**教**材**作**者**
- 涵**盖** 6 **大**人**格**理**论**流**派**
- 与**当**代**心**理**学**研**究**整**合**

## 6 大核心主题（人格理论流派）

### 1. 精神分析取向（Psychoanalytic Approach）

- **弗**洛**伊**德**（**S**i**g**m**u**n**d** **F**r**e**u**d**）**
  - **人**格**结**构** = **本**我**（**i**d**）** + **自**我**（**e**g**o**）** + **超**我**（**s**u**p**e**r**e**g**o**）**
  - **心**性**发**展**阶**段**（**口**、**肛**、**男**性**、**潜**伏**、**生**殖**）**
  - **潜**意**识**冲**突**是**神**经**症**的**根**源**
- **新**弗**洛**伊**德**
  - **霍**妮**：**社**会**文**化**神**经**症**
  - **沙**利**文**：**人**际**关**系**心**理**学**
  - **艾**里**克**森**：**心**理**社**会**发**展**阶**段**

### 2. 神经科学取向（Neuroscience Approach）

- **E**Y**N**S**S**（**E**xt**r**a**v**e**r**s**i**o**n**、**N**e**u**r**o**t**i**c**i**s**m**、**P**s**y**c**h**o**t**i**c**i**s**m**）**等
- **大**脑**和**人**格**的**关**系**
- **遗**传**和**环**境**的**相**互**作**用**

### 3. 行为主义取向（Behavioral Approach）

- **斯**金**纳**（**S**k**i**n**n**e**r**）**
- **人**格**是**学**习**的**产**物**
- **强**化**、**惩**罚**、**观**察**学**习**
- **班**杜**拉**（**B**a**n**d**u**r**a**）**的**社**会**学**习**理**论**

### 4. 人本主义取向（Humanistic Approach）

- **马**斯**洛**（**M**a**s**l**o**w**）**：**需**要**层**次**理**论**、**自**我**实**现**
- **罗**杰**斯**（**R**o**g**e**r**s**）**：**真**实**、**接**纳**、**共**情**
- **强**调**个**人**的**潜**能**和**成**长**

### 5. 认知取向（Cognitive Approach）

- **凯**利**（**K**e**l**l**y**）**的**个**人**构**念**理**论**
- **认**知**风**格**、**自**我**图**式**
- **人**格**是**信**息**加**工**的**方**式**

### 6. 特质取向（Trait Approach）

- **奥**尔**波**特**（**A**l**l**p**o**r**t**）**
- **卡**特**尔**（**C**a**t**t**e**l**l**）**的** 16**P**F**
- **艾**森**克**（**E**y**s**e**n**c**k**）**的** **P**E**N**
- **大**五**人**格**（**O**C**E**A**N**）**——**现**代**研**究**的**主**流**

## 大五人格模型（Big Five / OCEAN）

### 5 大维度

1. **开**放**性**（**O**p**e**n**n**e**s**s**）**—— **好**奇**、**创**造**
2. **尽**责**性**（**C**o**n**s**c**i**e**n**t**i**o**u**s**n**e**s**s**）**—— **自**律**、**可**靠**
3. **外**向**性**（**E**x**t**r**a**v**e**r**s**i**o**n**）**—— **热**情**、**活**跃**
4. **宜**人**性**（**A**g**r**e**e**a**b**l**e**n**e**s**s**）**—— **信**任**、**善**良**
5. **神**经**质**（**N**e**u**r**o**t**i**c**i**s**m**）**—— **情**绪**不**稳**定**

## 4 大研究方法

1. **自**陈**量**表**（**S**e**l**f**-**R**e**p**o**r**t**）**
2. **他**人**评**定**（**O**t**h**e**r**-**R**a**t**i**n**g**）**
3. **行**为**观**察**（**B**e**h**a**v**i**o**r**a**l** **O**b**s**e**r**v**a**t**i**o**n**）**
4. **生**理**测**量**（**P**h**y**s**i**o**l**o**g**i**c**a**l** **M**e**a**s**u**r**e**）**

## 4 大应用

1. **职**业**选**择**
2. **人**际**关**系**
3. **心**理**治**疗**
4. **个**人**成**长**

- "**我**是**什**么**人**？**"**
- "**人**格**是**天**生**的**吗**？**"**
- "**我**能**改**变**我**的**人**格**吗**？**"**

## 基本矛盾点

**稳**定**和**改**变**的**张**力**——

- **人**格**是**相**对**稳**定**的**
- **也**是**可**以**改**变**的**
- **改**变**需**要**时**间**和**努**力**

## 根本矛盾点

- **遗**传**有**重**要**作**用**
- **环**境**也**有**重**要**作**用**
- **两**者**相**互**作**用**——**不**是**二**元**的**
