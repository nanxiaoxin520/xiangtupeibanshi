## 📖 档案卡内容结构

每张档案卡包含（关系主题版）：

1. **基础信息** - 作者、ISBN、出版年
2. **核心内容** - 该书的核心概念和洞见
3. **核心问题** - 这本书讨论的核心议题
4. **基本矛盾点** - 该议题中的主要矛盾
5. **根本矛盾点** - 深层的结构性矛盾
6. **安慰和治疗** - 给使用者的安慰和疗愈话语
7. **解决方向** - 短期/中期/长期的具体方案
8. **心理咨询热线** - 中国本土有效热线
9. **重要的"未读"边界** - 诚实声明
