## 档案卡内容结构

每张档案卡包含：

1. **基础信息** — 作者、ISBN、出版年
2. **核心内容** — 该书的核心概念与洞见
3. **核心问题** — 这本书讨论的核心议题
4. **基本矛盾点** — 该议题中的主要矛盾
5. **根本矛盾点** — 深层的结构性矛盾
6. **安慰和治疗** — 给使用者的安慰与疗愈话语
7. **解决方向** — 短期/中期/长期的具体方案
8. **心理咨询热线** — 中国本土有效热线
9. **重要的「未读」边界** — 诚实声明

## 命名与规范

- 文件名：书名加全角书名号（如 《乡土中国》），扩展名为 .md
- frontmatter：扁平单行键值，含 title / author / isbn / publish_year / type / category / tags / aliases / related
- 标签：分级命名空间 `命名空间/子类/子子类`（主题 · 流派 · 方法 · 人物 · 文化 · 概念 · 典籍 · 类型），不含空格
- 内部链接：相关书籍使用 `[[《书名》]]` 双链，索引使用相对链接
