## 每个示例展示什么

- 用户实际输入
- 逐轮怎么接：一轮只做一件事（口径见 `SKILL.md`「说话方式」）
- 一句安慰为什么合格、为什么不合格
- 关键的安全边界
- 真实的中国本土资源

示例 01 额外给了一段**反面示范**：一条回复跑完 5 步、连发提问、通用安慰句。反面示范不是可复用话术。

示例 05 专讲安慰话术：几句现成话术各自为什么成立，以及「不劝她把原因想通」「隔天那一下」两处的落点。
